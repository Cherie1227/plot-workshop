# 剧情工坊 · Plot Workshop

面向手机使用的 SillyTavern 双模型大纲扩展：独立规划模型先确定这一轮的人物回应、情感变化与剧情，酒馆当前主模型再按大纲扩写中文正文。

当前版本 **0.1.0，测试版**。已通过本地模拟测试及四种尺寸的界面检查，尚未完成真实酒馆、Anima 服务和中转 API 的联调。

## 安装

在酒馆的 **扩展 → 安装扩展** 中粘贴以下地址，安装后刷新页面。在扩展设置或输入框旁的扩展菜单打开“剧情工坊”。

```text
https://github.com/Cherie1227/plot-workshop
```

也可下载仓库，将文件放进 `SillyTavern/public/scripts/extensions/third-party/plot-workshop/`。确保 `manifest.json` 直接位于这个目录中，不多套一层目录。无需运行构建命令或额外服务器。

手机访问电脑或服务器上的酒馆时，在运行酒馆的设备安装，手机刷新即可；安卓本机运行时放进本机的酒馆目录。

## 依赖与范围

- 酒馆最低声明版本为 **1.12.0**，运行时会检查所需接口；当前按官方 release 源码核对。
- Anima 适配核对 **Anima-Memory-System 3.3.6**，还需其原有的 anima-rag 后端和 TavernHelper。未核对的前端版本会明确提示。
- 首版支持单角色的普通发送。启用自动规划时，群聊、续写、滑动重生成等暂不支持。
- 规划模型使用 OpenAI 兼容 Chat Completions；正文沿用酒馆已有的模型、连接和预设。

## 使用

1. 先保证酒馆主模型和 Anima 正常工作。
2. 在本扩展“设置”填写独立规划接口地址、模型名称和密钥。请求经酒馆后端转发，不切换主连接；密钥只保存在当前页面内存，刷新后需重新填写。
3. 可配置两阶段共用的正文目标字数，例如 1500–2000；留空就不强加固定字数。大纲段数和长度由规划预设控制。
4. 使用内置“第三人称 · 轻度抢话”，或导入酒馆 JSON 预设并检查冲突条目。分组、条目可分别开关和编辑。
5. 填写本轮输入，生成大纲，查看或修改后确认扩写。也可选择自动扩写或仅生成大纲；“发送时自动规划”默认关闭。

## 大纲与记忆

输出为固定 XML 结构：`content` 内包含 `plot`、`characters`、`segments` 和 `end_state`。内容由规划模型决定；主模型展开叙述和自然对白，逐字保留的台词须在大纲标明。

自动注入的大纲只供当前请求使用，不写成聊天消息或 Anima 剧情事实。本浏览器会话可恢复最近一份大纲供查看，恢复后的旧纲需重新规划才可自动扩写。

“复制”和“填入输入框”支持手动使用；填入后若按普通用户消息发送，大纲会随该消息保存在历史里。

Anima 的重要记忆、Echo 寿命、保留数量、摘要与长期记忆规则沿用原设置。扩展等待本轮召回和动态聊天世界书容器更新完成，再生成大纲；同一轮重试与正文复用已完成的召回。更改输入、历史或相关设置后不会套用旧轮结果。

上游查询本身会更新 Echo，网络超时后的内部重试没有幂等或事务回滚保证。扩展避免已知重复请求，不改动上游这些行为。

## 预设兼容

支持常见完整酒馆预设和 Prompt Manager 的导出结构，保留启用顺序及分组。支持常用人物/输入宏和隔离的变量操作，不修改酒馆真实变量。

普通正文预设仍需关闭或修改与规划交付冲突的正文、状态栏等条目。未知宏、深度或条件注入会提示具体条目；不会默默略过。随机世界书触发和其他扩展的强制激活仍需实机验证。
